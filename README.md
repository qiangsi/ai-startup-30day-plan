# AI 创业 30 天验证计划

一个独立的中文单页网页，用于跟踪 AI 内容生产服务的首月创业验证。

## 在线预览

GitHub Pages 部署完成后，网址通常为：
https://qiangsi.github.io/ai-startup-30day-plan/

## 本地预览

直接用浏览器打开 `index.html`，无需安装依赖或构建。

## 功能

- 30 天执行清单与进度条
- 浏览器本地保存完成状态
- 客户访谈提纲与访谈记录
- 导出访谈记录为 TXT
- 首发服务设计、预算原则和第 30 天决策门槛

## 发布到 GitHub Pages

1. 打开仓库 Settings → Pages。
2. 在 Build and deployment 中选择 Deploy from a branch。
3. Branch 选择 `main`，目录选择 `/(root)`，点击 Save。
4. 等待部署完成。若页面未立即出现，稍等片刻后刷新 Pages 设置页。

这是纯静态网页，不需要 API 密钥或后端服务。清单和访谈记录仅保存在当前浏览器，不会自动同步到其他设备。
